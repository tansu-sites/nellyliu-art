# Nelly Liu Artist Website

Artist portfolio preview for `nellyliu.art`.

## Live URLs

- Production: https://nellyliu.art
- Vercel preview/production URL will be shown after deployment.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Notes

The artwork images currently use UniCredit Art Collection images as temporary placeholders for preview only. Replace them with Nelly Liu's final artwork images and captions before public launch.
